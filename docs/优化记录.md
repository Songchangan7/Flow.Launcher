支持在输入框中将 `C:\`、`C:/` 和 `C:` 统一识别为有效盘符路径并按 Windows 路径规范进行搜索。
为 Local Prompt Search 新增复制后恢复原输入窗口焦点能力，减少 `pt` 模板插入时的手动回切操作。
为 Local Prompt Search 增加复制后自动粘贴开关，默认仅复制并回焦，开启后回焦到原窗口并发送 `Ctrl+V`。
为 Browser Bookmarks 增加 Chrome 已打开标签页搜索与跳转能力，输入关键词时可在下拉结果中定位并切换到目标标签页。
在非技术用户使用说明中补充 Chrome 已打开标签页搜索与跳转功能的用途与操作步骤，便于直接上手。
