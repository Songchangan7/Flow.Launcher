# 非技术用户使用说明

## 这是什么

Flow Launcher 是一个用于快速启动应用、查找文件、执行常用操作的桌面效率工具。你可以把它理解为电脑上的“快速搜索框”。

## 如何打开

1. 安装并启动 Flow Launcher。
2. 按下默认快捷键打开搜索框。
3. 在搜索框中输入想要查找或执行的内容。

如果快捷键没有反应，请检查 Flow Launcher 是否正在运行，或在设置中重新配置快捷键。

## 常见使用方式

### 启动应用

在搜索框中输入应用名称，例如“浏览器”“记事本”或其他软件名称，然后选择结果并按回车。

### 查找文件

输入文件名的一部分，Flow Launcher 会显示匹配的文件或文件夹。选择目标后按回车即可打开。

### 打开网页

输入网址或搜索关键词，可以快速打开浏览器进行访问或搜索。

### 使用插件

Flow Launcher 支持插件来扩展功能。插件可以帮助你完成翻译、计算、搜索网页、管理剪贴板等操作。

## 基本设置

打开 Flow Launcher 设置后，你可以根据需要调整：

- 快捷键
- 外观主题
- 搜索结果数量
- 插件启用或禁用
- 文件搜索范围

如果不确定某个设置的作用，建议保持默认配置。

## 遇到问题怎么办

### 搜不到应用或文件

请确认应用或文件确实存在，并检查搜索关键词是否正确。如果是文件搜索问题，可以在设置中确认搜索范围是否包含对应文件夹。

### 快捷键打不开

可能是快捷键被其他软件占用。请进入设置，更换一个不常用的快捷键组合。

### 插件没有反应

请检查插件是否已启用。如果插件需要网络连接，请确认当前网络可用。

## 使用建议

- 输入关键词时尽量简短，例如输入应用名的前几个字。
- 常用功能可以通过插件增强。
- 如果不熟悉设置项，优先使用默认设置。
- 遇到异常时，先重启 Flow Launcher 再尝试。
