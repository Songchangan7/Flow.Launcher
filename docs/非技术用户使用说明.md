# 非技术用户使用说明

Flow Launcher 可以理解为电脑上的快速搜索框，用来快速打开应用、文件、网页和常用功能。

你可以先到 Flow Launcher 官网下载并安装，再开始使用。

官网地址：https://www.flowlauncher.com/

## 怎么用

1. 启动 Flow Launcher。
2. 按默认快捷键 `Alt + Space` 打开搜索框。
3. 输入你想找的内容，按回车执行。

## 你可以用它做什么

- 打开应用：输入应用名称，例如浏览器、记事本。
- 查找文件：输入文件名的一部分。
- 打开网页：输入网址或搜索关键词。
- 使用插件：完成翻译、计算、剪贴板等操作。

## 插件是怎么发挥作用的

可以把插件理解为一组分工不同的小工具。

当你在搜索框里输入内容时，Flow Launcher 会自动判断应该由哪个插件来处理。例如：

- 输入应用名称时，会调用查找应用的插件。
- 输入数学表达式时，会调用计算器插件。
- 输入搜索词或网址时，会调用网页相关插件。

这些插件会把结果返回给 Flow Launcher，再统一显示给你，所以用起来会像内置功能一样自然。

## `pm` 是什么

`pm` 是 Flow Launcher 自带的插件管理入口，用来安装、卸载和更新插件。

你可以这样使用：

- `pm install 插件名`：安装插件
- `pm uninstall 插件名`：卸载插件
- `pm update 插件名`：更新插件

如果只输入 `pm`，通常会先看到这些可选操作。

## 常用快捷键

- `Alt + Space`：打开搜索框
- `↑ / ↓`：在选项之间移动
- `← / →`：返回或进入上下文菜单
- `Esc`：返回查询界面
- `Enter`：打开或运行选中的项目
- `Shift + Enter`：打开上下文菜单
- `Ctrl + Enter`：打开所在目录
- `Ctrl + Shift + Enter`：以管理员身份运行，或在默认文件管理器中打开文件夹

## 常用设置

如果需要，可以在设置里调整这些内容：

- 快捷键
- 外观主题
- 搜索范围
- 搜索结果数量
- 插件启用状态

不确定怎么设置时，保持默认即可。
